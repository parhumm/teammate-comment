Nothing to learn

        
No tour, no tooltips, no coach marks. Selecting text to comment is one gesture, and everything else follows from it.

      

      

        
Select text
A Comment pill appears at the end of the selection.

        
C with text selected
The same thing without the mouse. Ignored while you are typing in a field.

        
Click a highlight
Opens its thread. Where highlights overlap, the smallest range wins, because it is the most specific thing you could have meant.

        
💬 launcher
Opens the sidebar: every thread on the page in document order, open ones counted on the badge.

        
Esc
Closes the composer or the open thread, then leaves select mode, then closes the sidebar.

        
#tc-<id> in the URL
Opens that thread and scrolls to it on load. Comments belong to a page, so ?utm_source=x lands on the same threads as the bare URL.

      

    

  


  

    

      

        
Hand the feedback to your assistant

        
Copy turns threads into Markdown: the page URL, a CSS path to the element each quote sits in, the quote, and every comment in order. Take one thread, pick a few in the sidebar, or copy everything, then paste it into an assistant and let it apply the edits.

Comments arrive where your team talks

        
Each project can have its own Telegram bot. Paste a token from @BotFather, press Start, and every new comment and reply lands in that chat with the page, the quoted text and the message. Add the bot to a group and the whole team sees it. On Slack, paste an incoming webhook and they post to that channel instead.

        
The Start link carries a code only your project knows, and only the chat that sends it is adopted, so a stranger who finds the bot cannot become the recipient. Delivery is fire-and-forget: a slow or blocked bot never delays a comment.

A guest on your page

      
Every conflict between the widget's clarity and your page's readability resolves toward your page.

      
    
        
  • It never rewrites your markup.Highlights paint over text ranges with the CSS Custom Highlight API, so copy-paste and find-in-page keep working.
    • 
        
  • It never asks for attention.With zero threads the launcher is a small neutral marker. It earns a count once something is open.
    • 
        
  • It never borrows your styles.The widget lives in a shadow root and sizes itself in pixels, so a host with a 10px root font cannot shrink it.
    • 
        
  • Amber means an open thread.Nothing else, anywhere. Resolved is the absence of amber plus a word, so color never carries meaning alone.

Painted highlights need Chrome 105, Safari 17.2 or Firefox 140. Below that the widget still loads and every thread is still reachable from the sidebar. Starting a thread is desktop-only for now; touch devices read, reply and resolve.

    

  


  

    

      

        
One Node process and one SQLite file

        
The server runs TypeScript directly on Node 22.18 or newer. No transpiler, no native modules, no database server. Put it behind anything that terminates TLS, set TC_PUBLIC_ORIGIN to its public address, and it is done.

        
The source is on GitHub, with deploy notes for a VPS behind a Cloudflare Tunnel.

      

      

        
Run it yourself

        
git clone https://github.com/parhumm/teammate-comment
cd teammate-comment
npm install
npm run build:widget
npm run start   # panel + API on http://localhost:8787
